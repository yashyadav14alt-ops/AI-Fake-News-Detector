# AI Fake News Detector 🔍

Detects fake news using Google Gemini AI. Paste any headline and get instant analysis!

## Features
- ✅ Real/Fake/Misleading verdict
- 📊 Confidence percentage
- 🚩 Red flags detection
- 💡 User advice
- 🗣️ Hinglish analysis

## Tech Stack
- Python
- Google Gemini API (gemini-2.0-flash)

## How to Use
1. Clone this repo
2. Install: pip install google-genai
3. Get API key from aistudio.google.com
4. Run: python fake_news_detector.py
